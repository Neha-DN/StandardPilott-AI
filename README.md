StandardPilott-AI 🇮🇳

AI-Powered Indian Standards Intelligence & Compliance Assistant

📌 About the Project

StandardPilott-AI is an AI-powered platform designed to simplify access to Indian Standards and BIS-related information. It helps manufacturers, MSMEs, startups and consumers understand applicable standards, product requirements and certification procedures.

The platform aims to make standards-related information more accessible through intelligent assistance, document analysis and guided compliance support.

🎯 Problem Statement

Businesses, especially MSMEs and startups, often face difficulties understanding complex Indian Standards, identifying applicable requirements and navigating BIS certification procedures.

StandardPilott-AI aims to simplify this process through an intelligent and user-friendly digital platform.

✨ Key Features

- AI Standards Assistant: Provides answers to questions related to Indian Standards and BIS services.
- Smart Standard Identification: Helps users identify potentially applicable standards based on product information.
- Compliance Gap Analysis: Helps identify missing information and potential compliance gaps in uploaded documents.
- Standard Change Analysis: Highlights differences between available versions of standards.
- Digital Compliance Passport: Organizes product-related standards and compliance records.
- Certification Guidance: Provides structured guidance and document checklists.
- Multilingual Assistance: Makes technical information easier to understand.

⚙️ Installation and Setup

1. Clone the repository:
   
   git clone https://github.com/Neha-DN/StandardPilott-AI.git

2. Navigate to the project directory:
   
   cd StandardPilott-AI

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL displayed in your terminal.
